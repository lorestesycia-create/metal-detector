Política de privacidad de Metal Detector

Última actualización: 7 de octubre de 2026.

Metal Detector utiliza el sensor magnético del dispositivo para mostrar mediciones del campo magnético y detectar variaciones. Las mediciones del sensor se procesan en el dispositivo.

Publicidad y consentimiento

La aplicación utiliza Google AdMob para mostrar anuncios. Google y sus socios pueden tratar información relacionada con el dispositivo, identificadores publicitarios e interacciones con anuncios para ofrecer, medir y proteger la publicidad, de acuerdo con las opciones de consentimiento del usuario y la legislación aplicable.

Cuando sea necesario, la aplicación solicitará el consentimiento mediante la plataforma de gestión de consentimiento de Google.

Permisos y acceso

La aplicación utiliza acceso a Internet para cargar publicidad. El sensor magnético se utiliza para la función de detección de la aplicación.

Servicios de terceros

Metal Detector utiliza Google AdMob. El tratamiento de datos realizado por Google está sujeto a las políticas y condiciones de Google.

Menores

La aplicación no está diseñada específicamente para menores ni pretende recopilar conscientemente información personal de menores.

Cambios

Esta política puede actualizarse para reflejar cambios en la aplicación, los servicios utilizados o los requisitos legales.

Contacto

Para consultas relacionadas con la privacidad, pueden utilizarse los datos de contacto del desarrollador publicados en la ficha de Metal Detector.
